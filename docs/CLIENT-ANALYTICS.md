# Аналитика обращений («База клиентов»)

Всё считается локально, без сети и без внешнего ИИ. Код:

| Модуль | Назначение |
|---|---|
| `js/features/client-analytics-parse.js` | Разбор .txt: кодировка, ИНН/КПП/ОГРН/телефоны/почта, дата обращения, очистка вопроса |
| `js/features/client-analytics-registry.js` | Коды регионов ФНС (первые 2 цифры ИНН/КПП), причины постановки на учёт (5–6 знаки КПП) |
| `js/features/client-analytics-text.js` | Нормализация, латинские двойники, токены, стоп-слова, основы, рубрикатор тем/намерений/срочности |
| `js/features/client-analytics-math.js` | Статистика, тесты, концентрация, энтропия, k-means, MinHash/LSH, union–find |
| `js/features/client-analytics-insights.js` | Расчёт всей аналитики за один проход (работает в Web Worker) |
| `js/features/client-analytics-charts.js` | SVG/HTML-графики с подсказками, без библиотек |
| `js/features/client-analytics-frogs.js` | Связка с чёрным списком: сопоставление, сравнение жаб с остальными, модель, гигиена списка |
| `js/features/client-analytics-dashboard.js` | Окно «Аналитика»: фильтры, вкладки, проваливание в записи, «рентген», экспорт |

## Принципы

1. Каждое число объяснимо: метод и порог описаны во вкладке «Методика».
2. Мало данных — вывод не делается: показывается «НЕТ ДАННЫХ ДЛЯ НАДЁЖНОГО ВЫВОДА».
3. Результат детерминирован (k-means с фиксированным зерном): одна база — одинаковые группы.
4. Дата обращения берётся только «уверенная»; если её нет, используется дата загрузки, и это видно.

## Источники справочных данных

- Коды 90–95 (Запорожская обл., Крым, Севастополь, ДНР, ЛНР, Херсонская обл.) и 99 (Байконур/иные
  территории) — справочник ФНС, приказ ФНС от 12.07.2023 № ЕД-7-21/470@; ИНН не меняется при переезде,
  текущий регион учёта отражается в КПП (письмо ФНС от 07.09.2018 № ГД-4-14/17499@).
- Причины постановки на учёт: 01 — по месту нахождения организации, 02/03 — старые коды филиалов (до 2008),
  43 — филиал, 44 — представительство, 45 — обособленное подразделение, 50 — крупнейший налогоплательщик,
  51–99 — иностранные организации. Источники расходятся в трактовке кода 50; принят вариант
  «крупнейший налогоплательщик».
- Частоты букв русского языка — НКРЯ (используются только как эталон для сравнения).
- MinHash/LSH: порог S-кривой ≈ (1/b)^(1/r); 16 полос × 4 строки ≈ 0,5, затем точная проверка Жаккара ≥ 0,6.

## Жабы (чёрный список)

| Совпадение | Сила | Пример |
|---|---|---|
| ИНН обращения = ИНН жабы | сильное | основной случай |
| второй ИНН в тексте обращения | сильное | «звоню от лица 7707083893» |
| телефон обращения = телефон жабы | сильное* | *телефон может быть общим у бухфирмы — см. «Соседи» и проверку списка |
| ИНН / телефон / e-mail из примечания жабы | сильное | «бухгалтер: +7 911 …» |
| название организации в тексте | слабое | уровень не присваивается, только подсказка |

Модель «похожести» использует только поведенческие признаки (число обращений, доли негатива, срочных,
жалоб, повторов ≤ 7 дней, ЗАГЛАВНЫХ, общий контакт с жабой, тип ИНН). Лексика в модель не входит,
иначе модель «подсматривала» бы ответ через слова, по которым сами жабы и определены. Это статистическое
сходство, а не основание для внесения в список.
