# Аудит Copilot 1СО — ноябрь 2026

## Как устроено приложение

- **Тип:** статическое PWA без сборки. `index.html` (≈370 КБ разметки, все модальные окна внутри) →
  `script.js` (≈4,9 тыс. строк связующего кода, ES-модули) → `js/entry.js` связывает модули с глобальными функциями.
- **Данные:** IndexedDB `DB_NAME` (≈30 хранилищ, `js/db/stores.js`), обёртка `js/db/indexeddb.js`
  (`performDBOperation` отдаёт результат записи только после commit транзакции).
  Резерв — `localStorage` (настройки, заметки при сбое БД).
- **Поиск:** собственный инвертированный индекс в хранилище `searchIndex` (слово → ссылки на записи
  с весами полей), префиксы, стемминг, синонимы, «семантическое» дополнение, BM25-подобное ранжирование
  (`js/features/search.js`, ≈4,8 тыс. строк).
- **Разделы:** главный алгоритм + «Информация по обращению» (заметки клиента), алгоритмы по разделам
  (1С/УП, СКЗИ, 1СО ЛК, Веб-Регистратор), ссылки 1С, внешние ресурсы, регламенты, закладки
  (rich-text, PDF-вложения, папки), база клиентов (разбор .txt, карточки, папки/теги, виртуальная сетка),
  обучение (учебник, наставник, SRS-карточки), шаблоны из Google Docs (Apps Script), типы СЭДО,
  чёрный список, анализатор XML (ZIP, кодировки, сертификаты), избранное, напоминания, корзина.
- **Офлайн:** Service Worker `sw.js` — precache оболочки + stale-while-revalidate для остального,
  кэш версионируется (`ASSET_QUERY_VERSION`).
- **Качество:** ≈170 тестовых файлов Vitest (jsdom + fake-indexeddb), фоновая самодиагностика
  («здоровье»), инженерный режим.

## Методика

Чтение кода по подсистемам; запуск приложения в Chromium (Playwright) с журналом консоли;
замеры времени запуска (первого и повторного) и нагрузочный тест на 6000 обращений;
обход всех неразрушающих кнопок во всех разделах и в шапке с перехватом ошибок JS;
сканирование доступности axe-core; проверка мобильной раскладки (390×844) на переполнение;
ESLint с правилами, ловящими реальные дефекты.

## Реализовано в этом проходе (47 пунктов)

### Производительность
1. Пакетная запись токенов записи в поисковый индекс одной транзакцией (`addManyToSearchIndex`).
2. Индекс заметок обновляется по разнице токенов «было/стало» — без полного прохода курсором по
   всему индексу на каждое автосохранение (`updateIndexByTokenDiff`).
3. Удалено ≈6 тыс. строк мёртвого кода: модули проверки отзыва сертификатов (в CHANGES.md
   значились удалёнными), дубликаты `js/app/algorithms.js`, `js/app/tabs.js`, `js/user-preferences*.js`,
   неиспользуемые `legacy-helpers`, `overlay-utils`, `template-loader` и др.

### Сохранность данных
4. Запрос постоянного хранилища (`navigator.storage.persist`) — браузер не вытеснит IndexedDB.
5. Предупреждение при заполнении хранилища на 85%.
6. Межвкладочная синхронизация (BroadcastChannel): при изменении данных в другой вкладке —
   предложение обновиться, чтобы не перезаписать их устаревшей копией.
7. Уведомление «Приложение открыто в нескольких вкладках».
8. **Автобэкап** в выбранную папку (File System Access API): раз в сутки, хранятся 14 последних копий,
   повторный запрос разрешения кнопкой, команды в палитре.
9. Напоминание о ручном бэкапе не показывается, пока автобэкап исправен; в нём кнопка «Включить автобэкап».
10. Заметки не теряются при закрытии вкладки сразу после набора (копия при `pagehide`, восстановление).
11. Резервная копия заметок в `localStorage` больше не игнорируется при доступной БД (побеждает более свежая).
12. Автоочистка корзины: старше 30 дней и сверх 500 записей.
13. Окно «Данные и хранилище»: занято/квота, записи по разделам, вес скриншотов и PDF, статус защиты.

### Корректность
14. Локальное время вместо UTC в именах файлов: экспорт базы, заметки .txt, чёрный список,
    отчёт слияния, диагностика, профиль оформления (6 мест).
15. Экран предупреждения ЧС закрывается при переходе в другой раздел (исправление было только в мёртвом дубликате).
16. Единый владелец Ctrl/Cmd+K (палитра), работает в русской раскладке; поиск больше не перехватывает сочетание.
17. Метка доступности поля «Пример / Список» перенесена в живой модуль.

### Поиск
18. Результат по алгоритму показывает совпавший шаг: «Шаг 3 · Идентификация проблемы — …».
19. Клик ведёт к шагу: прокрутка и подсветка на главной или в окне алгоритма.
20. Навигация ↓/↑/Enter/Esc по результатам (ARIA combobox/listbox).
21. Список результатов шире поля поиска на десктопе (заголовки не рвутся на 4 строки).
22. Человекочитаемые типы результатов («База клиентов», «Чёрный список» вместо имён хранилищ).
23. Описание результата в две строки; без пустого жёлтого прямоугольника на месте многоточия.

### Интерфейс
24. Индикатор автосохранения заметок («Сохранено в 14:05» / «Сохранение…» / «Ошибка сохранения»).
25. Пустой раздел алгоритмов: понятное пустое состояние, экспорт в PDF неактивен.
26. Телефоны в карточках базы клиентов: `+7 (903) 123-45-67`.

### Доступность

### PWA

## Найдено, но не сделано (бэклог)

Проверенные находки, отложенные из-за риска или объёма:

- Обновление индекса по разнице токенов для всех хранилищ (сейчас только заметки); остальные правки
  по-прежнему делают проход курсором по всему индексу — заметно на базах > 50 тыс. слов.
- Строгая CSP (`script-src 'self'`) — требует вынести ~6 inline-скриптов из `index.html`.
- `index.html` 370 КБ: модальные окна стоит грузить по требованию (`templates/` уже есть, но не используется).
- `script.js` (4,9 тыс. строк) — связующий код с ~40 глобальными функциями на `window`; разбить по модулям.
- Таймер: при запрете системных уведомлений срабатывает блокирующий `alert()` — заменить на звук +
  закреплённое уведомление (нужно решение владельца: alert осознанно привлекает внимание).
- Ошибка «Нет связи с Google Docs» показывается закреплённой при каждом запуске в сетях, где Google
  заблокирован; понижать до тихого статуса после N неудач подряд.
- Автобэкап: настройки интервала и числа копий в интерфейсе (сейчас 24 ч / 14 копий), восстановление
  из папки автобэкапа списком.
- История правок (`entityEditHistory`) не чистится для удалённых записей.
- Всплывающие уведомления перекрывают правый край выпадающего списка поиска.
- На первом запуске одновременно открываются предложение тура и ошибка Google Docs.
- Поисковый индекс по шагам алгоритма (сейчас шаг вычисляется при показе результата; ранжирование —
  по алгоритму целиком).
- 764 вызова `console.log` (за флагом отладки) — убрать из горячих путей.
