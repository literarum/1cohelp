# Изменения (ревизия качества)

Подробный отчёт — в сообщении ассистента. Кратко:

- Удалена проверка отзыва сертификатов (ФНС): вкладка, UI, код, сеть.
- Бэкап: защита от потери данных при импорте (нестроковые разделы), блок `integrity` (счётчики + SHA-256 по хранилищам), отказ при чужой/новой схеме, стартовые данные не воскресают после удаления.
- Здоровье: ложные ошибки при офлайне/недоступности внешних сервисов устранены; добавлена проверка структуры закладок.

- Service Worker: версии precache совпадают с `?v=`, ошибка записи в кэш не теряет ответ.
- Вёрстка: мобильные настройки, закладки, главная, HUD/модалки (z-index), XML-результат на всю ширину.

## Седьмой проход: поиск, палитра, тема по расписанию, повтор напоминаний (2026-11-17)

- **Поиск — опечатки.** Нечёткий поиск перебирал всего два варианта слова: заменял только первую букву и только на два символа. Поэтому «отчот» не находил «отчет». Теперь ищутся ближайшие слова в словаре поискового индекса (расстояние Дамерау — Левенштейна: одна правка для коротких слов, две — от 8 букв), для каждого из трёх первых слов запроса. Исправлено и в глобальном поиске, и в палитре команд.
- **Поиск — «Возможно, вы искали…».** Подсказка показывается и тогда, когда ничего не найдено (раньше она терялась). Убрано двойное экранирование кавычек в «ничего не найдено».
- **Поиск — фильтр по разделам.** Над результатами — «Все · Алгоритмы · Закладки · Ссылки и ресурсы · Регламенты · Клиенты · Прочее» со счётчиками (от 5 результатов из 2+ разделов). Выбор сохраняется для следующих запросов, навигация стрелками пропускает скрытые пункты.
- **Поиск — скорость правок.** Правка алгоритма, закладки, ссылки, ресурса, регламента, записи чёрного списка, папки или категории обновляет только изменившиеся слова индекса. Раньше каждая правка делала полный проход по всему индексу; точечное обновление было только у заметок.
- **Палитра команд.** У команд показаны горячие клавиши (на macOS — символами ⌘⌥⇧), при пустом запросе — заголовки «Недавние» и «Все команды».
- **Тема «Авто» по расписанию.** Настраивается в «Оформлении» под карточками темы: светлая с заданного времени, тёмная с заданного времени (интервал может переходить через полночь). Тема переключается сама, без мигания при загрузке; профили оформления не затрагиваются.
- **Повторяющиеся напоминания.** Каждый день, по будням, каждую неделю, каждый месяц (31-е в коротком месяце — последний день, затем снова 31-е). «Выполнено» переносит напоминание на следующий срок; пропущенные периоды не копятся.
- **E2E.** Проверка кадров оверлея по стадиям: кадр не пустой, цвета в гамме, ядро светится, вспышка ярче покоя, к концу всё гаснет, отрисовка кадра быстрее 120 мс.

## Правки по замечаниям владельца (2026-11-17)

- **Главный алгоритм:** убраны галки отметки пройденных этапов (модуль чек-листа удалён; его прежняя отметка чистится при запуске).
- **«Информация по обращению»:** под заметками больше не пишется «ИНН … в базе клиентов не найден». Строка появляется, только если ИНН есть в базе клиентов или в чёрном списке.
- **«Информация по обращению»:** кнопки перенесены в правую часть шапки, на одну строку с заголовком. Раньше при нехватке места они переносились под заголовок и прижимались влево.
- **Таймер:** при каждом запуске приложения — 01:50. Изменения кнопками «−/+» действуют до перезапуска. Идущий отсчёт и пауза посреди отсчёта при перезагрузке сохраняются.
- **Глобальный поиск:** браузер или менеджер паролей подставлял в поле сохранённое значение («100») уже после загрузки, принимая поиск за логин рядом со скрытым полем пароля «машинного отделения». Такое заполнение без нажатий клавиш теперь отбрасывается, а поле пароля помечено как не связанное с логином.
- **Настройки → Уведомления:** причина кривой вёрстки — конфликт классов. Стили редактора «Быстрых фраз» (`.ns-row` — сетка из колонок) применялись к строкам окна уведомлений. Классы фраз переименованы в `snp-*`. Дополнительно выровнены ползунок с подписью, счётчик и поля времени «Не беспокоить», убран пустой отступ.

## Изображения между строками закладки (2026-11-22)

- **Вставка в текст:** кнопка «Изображение» в панели редактора, Ctrl/Cmd+V прямо в описание или
  перетаскивание файла (синяя линия показывает место). Вставка в позицию курсора аккуратно делит абзац.
- **Настройка выбранного изображения** (плавающая панель): слева/справа с обтеканием, по центру, во всю
  ширину; размер 25/50/75/100 % или ручками по краям (привязка к 25/33/50/66/75/100 %); неразрушающее
  кадрирование (пропорции, сетка третей, клавиатура); подпись; описание для экранного диктора; замена;
  выше/ниже (Alt+↑/↓); просмотр на весь экран; удаление.
- **Безопасность правок:** общая история отмены для текста и изображений (Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z,
  в т.ч. в русской раскладке); набор текста при выделенном изображении не заменяет его; Backspace сначала
  выделяет изображение, затем удаляет.
- **Хранение:** в HTML только ссылка `data-shot="ID"` на запись `screenshots`; Blob в разметку не попадает.
  Черновики записываются в той же транзакции, что и закладка; удалённые из текста изображения удаляются
  при сохранении. Слияние баз перепривязывает ссылки; недоступное изображение показывается заглушкой.
- **Вложения:** изображения из текста не дублируются в галерее формы и окна просмотра; кнопка на миниатюре
  переносит вложение в текст.

## Седьмой проход: аналитика обращений и переработка разбора (2026-11-24)

- **Отображение:** карточка показывает исходный текст именно этого обращения (раньше — начало файла),
  телефоны в формате +7 (…), расшифровку ИНН (ЮЛ/ИП, регион, контрольная сумма) и КПП (регион, причина
  постановки); даты карточек и истории — дата обращения, а не загрузки; история клиента — профиль
  (ряд по месяцам, темы, интервалы); удаление в истории больше не перечитывает всю базу.
- **«Переобработать базу»:** старые записи заново разбираются из сохранённого текста файлов с сохранением id,
  папок и тегов.
- **Дашборд «Аналитика»** (фоновый поток, 100 000 обращений ≈ 8 с): динамика (Манн — Кендалл, Тейл — Сен,
  CUSUM, робастные всплески, сезонность, тепловая карта день×час), клиенты (Джини, Лоренц, HHI, повторы,
  регионы, связи через общие контакты), темы/намерения/срочность, смысловые группы (сферический k-means
  + силуэт), язык (Ципф, Хипс, энтропия, TF-IDF, коллокации, новые слова по G², буквенный профиль, опечатки,
  смешанная письменность), почти-дубликаты (MinHash + LSH), качество данных с интервалами Уилсона,
  «рентген» записи (каждое слово и необычный символ), экспорт JSON и CSV.

### Связка с чёрным списком («жабы»)

- **Сопоставление по пяти признакам:** ИНН обращения, второй ИНН в тексте, телефон, ИНН/телефоны/e-mail из
  примечания к записи ЧС (сильные — дают уровень) и название организации в тексте (слабое — подсказка).
- **Вкладка «Жабы» в аналитике:** покрытие списка; чем жабы отличаются от остальных (U-тест Манна — Уитни,
  z-тест долей, отношения шансов по темам с 95% ДИ, характерные слова по G²); градиент по уровню (ρ Спирмена);
  темп обращений до/после внесения в список; доля жаб по месяцам; «соседи» — другие ИНН с теми же
  телефонами/почтой; модель похожести на жабу (логистическая регрессия, AUC на 5-кратной перекрёстной
  проверке, кандидаты скрываются при AUC < 0,6); проверка самого списка (неверные ИНН, дубли, записи без
  ключей, нераспознанные телефоны, телефон жабы у другого ИНН).
- **Везде в аналитике:** фильтр «все / только жабы / без жаб», значок жабы в списках записей, в «рентгене»
  (с указанием, по чему найдено, и переходом к записи ЧС), в топе клиентов и группах связанных клиентов,
  выводы на «Обзоре», столбцы в CSV.
- **Карточки базы клиентов:** значок жабы и при совпадении только по телефону («· по тел.»).
- **Окно записи в «Чёрном списке»:** блок «Обращения в базе клиентов» — число, период, сколько после
  внесения в список, последние обращения и кнопка «Вся история обращений».

### Восьмой проход: прогноз, свои темы, сравнение периодов, строгая статистика (2026-11-24)

- **Найдена и исправлена ошибка:** повторный пересчёт аналитики на выборке > 1500 обращений (смена
  фильтров, «Пересчитать», сохранение темы) молча отбрасывался — счётчик актуальности расчёта
  сдвигался идентификатором сообщения воркеру.
- **Множественные сравнения:** во всех семействах проверок (темы и намерения, сравнение периодов,
  жабы против остальных, «новые» и характерные слова) — поправка Бенджамини — Хохберга (q < 0,05,
  для слов q < 0,01). На данных без настоящих различий ложные «значимые» темы исчезли (было 3 из 25).
- **Тест темпа обращений** — с квазипуассоновской поправкой на волновой поток (z/√φ).
- **Прогноз на 14 дней** (вкладка «Динамика»): «как неделю назад», среднее того же дня недели за
  4 недели, Холт — Винтерс с затухающим трендом; выбор по MASE на скользящем бэктесте, эмпирические
  80/95%-интервалы и их фактическая калибровка, прогноз на следующую неделю.
- **Свои темы:** редактор ключевых слов (начало слова, фразы, «*»), живой подсчёт совпадений,
  хранение в базе; темы сразу участвуют во всей аналитике, включая жаб и CSV. Подсказки — частые
  слова в обращениях без темы.
- **Сравнение двух произвольных периодов:** темп, клиенты (новые/ушедшие), темы, намерения, сигналы
  (срочные, негатив, доля жаб), слова, которые учащаются и уходят.
- **Слова:** формы одного слова, которые стеммер разносил по разным основам («обращение»/«обращения»,
  «ошибка»/«ошибок», «отчётность»/«отчётности»), объединяются; «отчёт» и «отчётность» остаются разными.
- **Жабы по всему приложению:** уведомление при загрузке файла, если в нём есть обращения жаб; фильтр
  «Жабы» (все / только жабы / только гипержабы / без жаб) в панели раздела; число обращений и дата
  последнего прямо в таблице «Чёрного списка» (пересчитывается при изменении базы клиентов).
- **Доступность:** контраст ссылок, зелёного «снижения» и подписей на жёлтых плитках доведён до
  WCAG AA; axe — 0 нарушений на всех 10 вкладках в обеих темах.
