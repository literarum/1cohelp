# Изменения (ревизия качества)

Подробный отчёт — в сообщении ассистента. Кратко:

- Удалена проверка отзыва сертификатов (ФНС): вкладка, UI, код, сеть.
- Бэкап: защита от потери данных при импорте (нестроковые разделы), блок `integrity` (счётчики + SHA-256 по хранилищам), отказ при чужой/новой схеме, стартовые данные не воскресают после удаления.
- Здоровье: ложные ошибки при офлайне/недоступности внешних сервисов устранены; добавлена проверка структуры закладок.
- XML-анализатор: кодировки (UTF-8/16, windows-1251, koi8-r), ZIP без сети, лимиты, понятные ошибки, защита от XXE/entity-бомб, namespace-корни.
- Service Worker: версии precache совпадают с `?v=`, ошибка записи в кэш не теряет ответ.
- Вёрстка: мобильные настройки, закладки, главная, HUD/модалки (z-index), XML-результат на всю ширину.

## Второй проход: 55 дополнительных исправлений (2026-10-01)

**Безопасность:** XSS в XML-анализаторе (createField/accordion через innerHTML), XSS в корзине «Недавно удалённые», отклонение `javascript:/data:/vbscript:` URL в закладках.
**Данные/бэкапы:** запись в IndexedDB считается успешной только после commit транзакции (`performDBOperation`, `saveDataToIndexedDB`); блокировка сохранения после неудачной загрузки; корзина сохраняет Blob (structuredClone); merge восстанавливает Blob из base64, перепривязывает `screenshotIds`, перечитывает алгоритмы в память; импорт очищает корзину/историю правок и их localStorage-зеркала; `entityEditHistory` исключена из экспорта; защита undo от записей скриншотов без Blob; усечение зеркала истории; экспорт в браузерах без File System Access больше не возвращает ложный «сбой».
**Поиск:** защита от устаревших ответов `performSearch`; индекс очищается при любом update; подсветка не ломает HTML-сущности (`&amp;`); поиск в чёрном списке учитывает ё/е, телефон по цифрам, организации без `organizationNameLc`.
**UX/надёжность:** двойной вызов палитры команд, слушатель Escape в backup-reminder (capture), таймер >24.8 дней, двойная отправка закладки/напоминания, устаревшие PDF в форме закладки, утечки object URL и `dragend`, наложение confirm/alert, Escape напоминания под другой модалкой, гонка id уведомлений, баннер обновления SW после «Позже», SRS-интервал (масштаб не накапливается), `role="dialog"` у 8 модалок, aria-label у кнопок/фильтра, `<meta description>`, `<noscript>`.
**Производительность:** lazy-загрузка pdf-lib/fontkit/xlsx, единый экземпляр import-export, gate консоли (`localStorage.copilotDebug='1'`), ограничение boot-лога, throttle scroll-nav, негативный кэш Google Docs, лимиты `fingerprintStats` и кэша SW (оболочка не вытесняется), ignoreSearch в SW только офлайн, отсрочка `revokeObjectURL`.
**Прочее:** защита от формул в Excel (пробелы/tab/CR), `*жирный*` в Google Docs, AbortError не считается сбоем сети, локальная дата в имени экспорта.
