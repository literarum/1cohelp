# Изменения (ревизия качества)

Подробный отчёт — в сообщении ассистента. Кратко:

- Удалена проверка отзыва сертификатов (ФНС): вкладка, UI, код, сеть.
- Бэкап: защита от потери данных при импорте (нестроковые разделы), блок `integrity` (счётчики + SHA-256 по хранилищам), отказ при чужой/новой схеме, стартовые данные не воскресают после удаления.
- Здоровье: ложные ошибки при офлайне/недоступности внешних сервисов устранены; добавлена проверка структуры закладок.
- XML-анализатор: кодировки (UTF-8/16, windows-1251, koi8-r), ZIP без сети, лимиты, понятные ошибки, защита от XXE/entity-бомб, namespace-корни.
- Service Worker: версии precache совпадают с `?v=`, ошибка записи в кэш не теряет ответ.
- Вёрстка: мобильные настройки, закладки, главная, HUD/модалки (z-index), XML-результат на всю ширину.

**UX/надёжность:** двойной вызов палитры команд, слушатель Escape в backup-reminder (capture), таймер >24.8 дней, двойная отправка закладки/напоминания, устаревшие PDF в форме закладки, утечки object URL и `dragend`, наложение confirm/alert, Escape напоминания под другой модалкой, гонка id уведомлений, баннер обновления SW после «Позже», SRS-интервал (масштаб не накапливается), `role="dialog"` у 8 модалок, aria-label у кнопок/фильтра, `<meta description>`, `<noscript>`.
**Производительность:** lazy-загрузка pdf-lib/fontkit/xlsx, единый экземпляр import-export, gate консоли (`localStorage.copilotDebug='1'`), ограничение boot-лога, throttle scroll-nav, негативный кэш Google Docs, лимиты `fingerprintStats` и кэша SW (оболочка не вытесняется), ignoreSearch в SW только офлайн, отсрочка `revokeObjectURL`.
**Прочее:** защита от формул в Excel (пробелы/tab/CR), `*жирный*` в Google Docs, AbortError не считается сбоем сети, локальная дата в имени экспорта.

## Четвёртый проход: оверлей загрузки, аудит кастомизации, дизайн (2026-11-16)

- **Дизайн:** волосяные границы и мягкая глубина панелей и карточек, единые кнопки и фокус полей;

## Шестой проход: оверлей загрузки «Рождение звезды» (2026-11-17)

Рендерер `js/features/loading-overlay/sphere-renderer.js` переписан с нуля под тот же API (`start/stop/finish/renderAt/setTheme`) и те же настройки (длительность, финал, палитра):

- **Фон:** процедурные туманности (46 облаков вдоль диагональной «ленты»), ~650 статичных звёзд и 14 ярких звёзд с дифракционными бликами — отрисовываются один раз; медленный параллакс; мерцающие звёзды; падающие звёзды по детерминированному расписанию.
- **Галактический диск:** ~1500 частиц в двух спиральных рукавах, дифференциальное вращение (ω ∝ r^-1.5), цвет от горячего синего у центра к маджента на краю, шлейфы движения; задняя половина проходит за планетой.
- **Планета:** освещение по Ламберту, объёмный блик и светящаяся кромка, каркас-меридианы, атмосфера, внутренние энергетические потоки; тело перекрывает задний диск.
- **Орбиты:** три наклонные орбиты с тонкими линиями, частицами и «лунами» с ореолом и хвостом.
- **Ядро:** многослойное свечение, анаморфный блик, 6 вращающихся дифракционных лучей, мерцающая корона.
- **Финал (2,1 с):** спиральное засасывание с ускорением вращения и наездом камеры → вспышка с анаморфной полосой → три ударные волны с хроматической аберрацией → ~1100 обломков с сопротивлением среды, закруткой и остыванием цвета (белый → палитра) и 16 огненных фрагментов с длинными шлейфами → расширяющаяся туманность-остаток; встряска камеры. Гашение фона оверлея синхронизировано с концом сжатия (570 мс).
- **Производительность:** без `shadowBlur` и `ctx.filter`; статичные слои (фон, тело и атмосфера планеты, туманность-остаток в 1/4 разрешения) отрисовываются заранее; шлейфы — пачками по цвету; дальняя полусфера не рисуется; фон копируется без ресэмплинга. В программной отрисовке (headless Chromium, 1440×900) — ~57 кадр/с в покое, финал — 100 кадров за 2,1 с (старая версия — 85).

## Седьмой проход: поиск, палитра, тема по расписанию, повтор напоминаний (2026-11-17)

- **Поиск — опечатки.** Нечёткий поиск перебирал всего два варианта слова: заменял только первую букву и только на два символа. Поэтому «отчот» не находил «отчет». Теперь ищутся ближайшие слова в словаре поискового индекса (расстояние Дамерау — Левенштейна: одна правка для коротких слов, две — от 8 букв), для каждого из трёх первых слов запроса. Исправлено и в глобальном поиске, и в палитре команд.
- **Поиск — «Возможно, вы искали…».** Подсказка показывается и тогда, когда ничего не найдено (раньше она терялась). Убрано двойное экранирование кавычек в «ничего не найдено».
- **Поиск — фильтр по разделам.** Над результатами — «Все · Алгоритмы · Закладки · Ссылки и ресурсы · Регламенты · Клиенты · Прочее» со счётчиками (от 5 результатов из 2+ разделов). Выбор сохраняется для следующих запросов, навигация стрелками пропускает скрытые пункты.
- **Поиск — скорость правок.** Правка алгоритма, закладки, ссылки, ресурса, регламента, записи чёрного списка, папки или категории обновляет только изменившиеся слова индекса. Раньше каждая правка делала полный проход по всему индексу; точечное обновление было только у заметок.
- **Палитра команд.** У команд показаны горячие клавиши (на macOS — символами ⌘⌥⇧), при пустом запросе — заголовки «Недавние» и «Все команды».
- **Тема «Авто» по расписанию.** Настраивается в «Оформлении» под карточками темы: светлая с заданного времени, тёмная с заданного времени (интервал может переходить через полночь). Тема переключается сама, без мигания при загрузке; профили оформления не затрагиваются.
- **Повторяющиеся напоминания.** Каждый день, по будням, каждую неделю, каждый месяц (31-е в коротком месяце — последний день, затем снова 31-е). «Выполнено» переносит напоминание на следующий срок; пропущенные периоды не копятся.
- **E2E.** Проверка кадров оверлея по стадиям: кадр не пустой, цвета в гамме, ядро светится, вспышка ярче покоя, к концу всё гаснет, отрисовка кадра быстрее 120 мс.

## Правки по замечаниям владельца (2026-11-17)

- **Главный алгоритм:** убраны галки отметки пройденных этапов (модуль чек-листа удалён; его прежняя отметка чистится при запуске).
- **«Информация по обращению»:** под заметками больше не пишется «ИНН … в базе клиентов не найден». Строка появляется, только если ИНН есть в базе клиентов или в чёрном списке.
- **«Информация по обращению»:** кнопки перенесены в правую часть шапки, на одну строку с заголовком. Раньше при нехватке места они переносились под заголовок и прижимались влево.
- **Таймер:** при каждом запуске приложения — 01:50. Изменения кнопками «−/+» действуют до перезапуска. Идущий отсчёт и пауза посреди отсчёта при перезагрузке сохраняются.
- **Глобальный поиск:** браузер или менеджер паролей подставлял в поле сохранённое значение («100») уже после загрузки, принимая поиск за логин рядом со скрытым полем пароля «машинного отделения». Такое заполнение без нажатий клавиш теперь отбрасывается, а поле пароля помечено как не связанное с логином.
- **Настройки → Уведомления:** причина кривой вёрстки — конфликт классов. Стили редактора «Быстрых фраз» (`.ns-row` — сетка из колонок) применялись к строкам окна уведомлений. Классы фраз переименованы в `snp-*`. Дополнительно выровнены ползунок с подписью, счётчик и поля времени «Не беспокоить», убран пустой отступ.
